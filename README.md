A make.fun bounty entry: the scariest horror story I can tell in exactly two sentences.

## The story

> I taught my smart speaker to answer only to my voice, so the house would never obey a stranger. At 2 AM it answered a voice from the nursery anyway, and the voice it answered was mine.

## How it works

`main.ts` writes the fixed story text to `/output/entry.txt`. The text is a
constant in the source, so every run produces byte-identical output. No
network, no randomness, no external input.

Run it with:

```sh
node main.ts
```
